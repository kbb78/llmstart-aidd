### 2. Конфиг и запуск
> Бот стартует, пишет провайдер и модель в лог. При невалидном конфиге падает с понятной ошибкой.

- [x] `Config` — читает `.env`, валидирует обязательные переменные
- [x] `__main__.py` — инициализирует логирование, собирает объекты, запускает бота

### 3. Telegram: приветствие
> Бот отвечает на `/start` и молчит на всё остальное.

- [x] `TelegramBot` — long polling, хендлер `/start`
- [x] Нетекстовые сообщения игнорируются

### 4. Ответ через LLM
> Бот отвечает на текстовые сообщения. Роль задана через `SYSTEM_PROMPT`.

- [x] `LlmClient` — вызов chat completions, один метод
- [x] `Assistant` — системный промпт + входящий текст → ответ
- [x] Хендлер текста в `TelegramBot` вызывает `Assistant`
- [x] При ошибке LLM — фиксированная фраза пользователю, исключение в лог

### 5. История диалога
> Бот помнит контекст разговора. При переполнении лимита старые реплики удаляются.

- [x] `ChatHistory` — история по `chat_id`, лимит `MAX_HISTORY_MESSAGES`
- [x] `Assistant` использует историю при каждом вызове LLM
- [x] Неуспешный вызов LLM не пишет реплику в историю
