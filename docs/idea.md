# Идея проекта: LLM-ассистент в Telegram.

## Описание

Разработка интеллектуального ассистента на базе LLM, реализованного в виде Telegram-бота.

## Основная функциональность

Бот ведет диалог с пользователем и отвечает на его вопросы, придерживаясь определённой роли, заданной в системном промпте языковой модели. Это позволяет настроить поведение ассистента под конкретные задачи и сценарии использования.

## Ключевые особенности

- **Платформа**: Telegram
- **Формат взаимодействия**: Текстовый диалог
- **Персонализация**: Настраиваемая роль через системный промпт
- **Доступность**: Бот развёрнут в облаке Railway и доступен 24/7 без запуска на локальной машине

## Роль: Онлайн-преподаватель

Бот настроен на роль онлайн-преподавателя:

- **Объяснение тем** — по запросу пользователя развёрнуто объясняет любую тему
- **Уточняющие вопросы** — отвечает на вопросы по объяснённому материалу
- **Проверка знаний** — после объяснения задаёт 1–2 проверочных вопроса для закрепления материала

Роль задаётся через переменную `SYSTEM_PROMPT` и может быть заменена без изменения кода.

## Целевая аудитория

Пользователи, которым необходим быстрый доступ к интеллектуальному помощнику через привычный интерфейс Телеграм.
