# ADR 0004. История диалога в памяти

**Статус:** принято

## Контекст

Модели нужен контекст предыдущих реплик. Для проверки идеи устойчивость после рестарта не требуется.

## Решение

История хранится в памяти процесса, без БД и файлов.

## Следствия

Рестарт бота очищает диалоги. Несколько инстансов бота не делят историю. Постоянное хранение — отдельное решение, если идея подтвердится.
