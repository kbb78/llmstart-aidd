# ADR 0007. Ручная сборка, промпт в .env, без стриминга

**Статус:** принято

## Контекст

Нужна схема связей классов и место системного промпта. Стриминг в Telegram усложняет хендлер.

## Решение

Сборка графа объектов — в `__main__.py`. Роль ассистента — `SYSTEM_PROMPT` в `.env`. Ответ пользователю отправляется одним сообщением после полного ответа модели.

## Следствия

Смена роли — правка `.env` и перезапуск. Отдельный файл промпта и стриминг — отдельные решения, если понадобятся.
