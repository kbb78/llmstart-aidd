# ADR 0006. Плоский пакет src/assistant

**Статус:** принято

## Контекст

Нужна структура кода без лишних слоёв. Правило: один класс — один файл.

## Решение

Корень пакета: `src/assistant/`. Пять классов: `Config`, `LlmClient`, `ChatHistory`, `Assistant`, `TelegramBot`. Хендлеры Telegram — методы `TelegramBot`. Сборка объектов — в `__main__.py`.

## Следствия

Нет пакетов `core` / `infrastructure` / `domain`. Новые файлы появляются только вместе с новым классом, без которого нельзя обойтись.
