# ADR 0009. Сценарии: текст, /start, без /reset

**Статус:** принято

## Контекст

Нужен минимальный набор действий бота для проверки идеи.

## Решение

Команды: только `/start` (приветствие, история не трогается). Рабочий сценарий — текстовые сообщения. Нетекст игнорируется. При ошибке LLM реплика пользователя в историю не попадает. `/reset` нет.

## Следствия

Меньше кода в `TelegramBot`. Чтобы сбросить контекст — перезапуск процесса.
