# ADR 0002. Telegram: aiogram, long polling

**Статус:** принято

## Контекст

Бот должен принимать текстовые сообщения из Telegram. Webhook требует публичный HTTPS-endpoint.

## Решение

Библиотека aiogram 3. Доставка обновлений — long polling.

## Следствия

Для локальной проверки не нужен сервер и TLS. Переход на webhook — отдельное решение, если появится постоянный хостинг.
