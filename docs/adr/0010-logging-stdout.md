# ADR 0010. Логи: stdout, тексты диалога

**Статус:** принято

## Контекст

Для проверки идеи нужно видеть, что ушло в модель и что вернулось. Отдельный стек логов не нужен.

## Решение

`logging` в stdout. В лог пишем `chat_id` и тексты реплик пользователя и модели. Секреты не логируем. Файлов и внешних систем нет.

## Следствия

Логи содержат персональные сообщения. Для локальной проверки это приемлемо. На общем хосте решение нужно пересмотреть.
