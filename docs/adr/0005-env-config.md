# ADR 0005. Конфигурация через .env

**Статус:** принято

## Контекст

Бот нуждается в токене Telegram, ключе и URL LLM, имени модели. Значения разные для OpenRouter и Ollama. Их нельзя хранить в репозитории.

## Решение

Все параметры запуска читаются из переменных окружения. Локально задаются файлом `.env`. В git — только `.env.example` с пустыми или фиктивными значениями.

## Следствия

Имена переменных зафиксированы в `docs/vision.md`, раздел «Конфигурирование». Смена провайдера — `LLM_PROVIDER` и перезапуск.
