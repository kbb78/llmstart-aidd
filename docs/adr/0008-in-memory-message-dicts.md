# ADR 0008. История: словари OpenAI, лимит 20

**Статус:** принято

## Контекст

Нужен контекст диалога без БД. Отдельная сущность Message увеличит число файлов без выигрыша.

## Решение

История — `dict[chat_id, list[dict]]` с полями `role` и `content`. Системный промпт в словарь не кладём. Потолок — 20 реплик на чат, задаётся `MAX_HISTORY_MESSAGES`.

## Следствия

Рестарт очищает историю. Рост памяти ограничен лимитом. Смена формата сообщений API затронет `ChatHistory` и `LlmClient`.
