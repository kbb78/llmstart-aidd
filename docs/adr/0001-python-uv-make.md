# ADR 0001. Python, uv, Make

**Статус:** принято

## Контекст

Нужен минимальный стек для проверки идеи Telegram-бота с LLM.

## Решение

- Язык: Python 3.12+.
- Зависимости и окружение: `uv`, манифест `pyproject.toml`.
- Пользовательские команды: `make` как обёртка над `uv` (install, run).

## Следствия

Один источник зависимостей — `pyproject.toml`. `requirements.txt` не ведём. Make не дублирует логику сборки.
